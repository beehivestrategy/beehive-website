How we protect data

Encryption & Isolation by Default

Every deployment starts from a zero-trust baseline, not an enterprise upsell.

01

Encrypt everything

All data is encrypted in transit with TLS 1.3 and at rest with AES-256.

02

Per-tenant isolation

Client data is fully isolated; one client's data is never visible to another.

03

Role-based access

Least-privilege access with complete audit logging on every action.

04

No raw data to LLMs

Raw client data never leaves the secure environment and is never sent to model prompts.

05

Aggregated only

Only aggregated, anonymised query results are sent to enterprise-grade LLM providers.

06

Human review option

Enterprise clients can require human review before any AI answer is delivered.

AI governance

We Never Train on Your Data

Our governance model is the product. It is not a checkbox we add at the end.

01

No model training

Client data is never used to train any LLM. Models are general-purpose and pre-trained.

02

Prompt boundary

Only aggregated, anonymised results reach the model for natural-language generation.

03

Auditability

Every query, answer, and data access is logged and reviewable on request.

Raw rows never cross the boundary. The model sees a summarised result, never the underlying records — and enterprise clients can require a human checkpoint before an answer is delivered.

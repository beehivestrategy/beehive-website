# MCP Integration Skill

## Instructions

When the user asks about implementing MCP for their organization:

1. **Architecture Assessment**: Evaluate existing data infrastructure — databases, APIs, BI tools, data warehouses
2. **MCP Server Design**: Recommend which data sources to expose via MCP servers
3. **Security Review**: Assess authentication, authorization, and data governance requirements
4. **Integration Plan**: Create a phased rollout plan connecting MCP to existing AI assistants
5. **ChatBI Connection**: Explain how MCP servers connect to conversational BI interfaces

## Key Topics

- MCP vs REST/GraphQL for enterprise data
- MCP server architecture patterns
- Security considerations (OAuth, scoped permissions, data masking)
- MCP + semantic layer integration
- Real-time vs batch data access patterns

# ChatBI Assessment Skill

## Instructions

When the user wants to evaluate Conversational BI readiness:

1. **Current State Assessment**: Map existing BI tools, data sources, and user adoption rates
2. **Semantic Layer Evaluation**: Check if a semantic layer exists and if it supports natural language queries
3. **NLQ Capability**: Assess text-to-SQL accuracy, query understanding, and response quality
4. **User Accessibility**: Measure what percentage of non-technical users can access data today
5. **ROI Projection**: Calculate expected adoption improvement and time-to-insight reduction

## Key Metrics

- Current analytics adoption rate (% of employees using BI tools)
- Query response time improvement potential
- Self-service analytics maturity score
- Data governance readiness for conversational access

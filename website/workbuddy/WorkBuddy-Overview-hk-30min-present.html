WorkBuddy 是什麼

產品定義、與一般 AI 的差別、今天的市場位置

PART 01 / 08
產品定義EXHIBIT 11.2 min

一個能把工作做完的工作台

① 自然語言理解

不用學指令、不用記語法。用日常語言把需求說清楚就行，門檻低到不需要培訓。

② 自主規劃執行

複雜任務自動拆成多步，依次調用工具執行，過程中自我校驗與修正，直到目標完成。

③ 多模態任務處理

理解與生成文字、圖像、表格、代碼；能解析文件與圖表，也能產出多模態成果。

④ 本地文件操作

在授權目錄內直接讀取與寫入文件，資料整理、文件生成、批次處理，成果直接存檔。

一句話定位

騰訊出品的全場景 AI 辦公工作台，覆蓋日常辦公、代碼開發與設計創意，用戶以自然語言下達任務，它自主思考、拆解、規劃，最後交付可直接驗收的結果。

重點拿到的是成品，可以直接進流程；不是一段還要自己整理的回答。

它做得到什麼

PART 02 / 08
場景總覽EXHIBIT 61.2 min

先從這四類工作開始：團隊裏最重複的那些

場景一市場調研

多源資料蒐集、交叉比對、結構化結論，直接出可讀的報告。

怎麼做　拆成「行業 / 公司 / 資本 / 監管」幾條線分別蒐集，再交叉比對。

典型輸入　一個業務問題 + 幾份公開資料
典型交付　行業趨勢報告 · 競品對照 · 供應商與選品清單

場景二內容生產

一個主題，多平台成套產出，文案、配圖、腳本一次到位。

怎麼做　同一個核心資訊，按各平台要的長度與語氣分別改寫，風格統一。

典型輸入　一個主題 + 品牌定義
典型交付　社媒貼文 · 圖文素材 · 短片腳本 · Landing Page 文案

場景三網站 / 軟件開發

不會寫代碼也能交付應用，從頁面到可瀏覽的站點。

怎麼做　拆需求 → 選方案 → 寫代碼 → 本地跑通 → 修報錯 → 交付網址。

典型輸入　一句需求描述
典型交付　Landing Page · 小工具 · 內部系統 · 數據儀錶板

場景四數據分析

表格丟進去，結論、圖表、異常點一起拿出來。

怎麼做　多表關聯清洗 → 找異常與歸因 → 出圖表 → 寫成可直接發的月報。

典型輸入　一份或幾份表格
典型交付　分析結論 · 可視化圖表 · 週報月報 · 異常清單

重點這四類不是「AI 能不能做」的問題，是今天誰在做、花了多久的問題。

PART 05 / 08
企業版EXHIBIT 301.2 min

企業版：讓 AI 可管、可控、可算帳

01

管人

集中式成員管理與企業級存取控制，幾分鐘內把團隊加進來。

· 連結邀請或 SSO 同步（企業微信 / 飛書 / SAML）
· 角色權限：管理員 / 成員 / 查看者
· 成員加入審批流程
· 每人月度額度（預設 1,000 / 月，可調）
· IP 白名單與存取日誌

02

管 AI

一次構建，全團隊共享，資產集中在管理後台。

· 企業 Agent 平台：建立 / 版本管理 / 部署
· 團隊共享的技能庫與專家包
· 企業知識庫 + 檢索：貴公司的文件，貴公司的上下文
· 自定義提示詞與 Playbook，統一工作規範
· 助理遠程控制

03管錢 & ROI

AI 到底省了多少：有數可看，有防護機制可設。

· 研發效率儀錶板：任務量 / 節省時間 / 使用率
· 按成員查看用量明細（模型 / 工具 / 時間維度）
· 預算上限 + 額度臨近自動告警
· 額度加量包與座位彈性擴容
· 發票匯出，企業對帳

重點企業版回答的不是「好不好用」，是「敢不敢讓全公司用」。
